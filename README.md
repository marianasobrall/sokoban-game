# Sokoban Game

A Python implementation of the classic Sokoban puzzle game, built with Pygame as a project for the Object-Oriented Programming (POO) course at Iscte.

## About

The player pushes boxes onto target slots across a series of levels, loaded from text-based level files. The project demonstrates core OOP concepts: class hierarchies for game elements, exception handling for invalid level configurations, and decorators.

## Features

- Turn-based grid movement (arrow keys or WASD)
- Custom level loading from text files, with validation and error handling
- Multi-level progression
- Player performance tracking (steps taken, time to complete)

## Tech Stack

- Python
- Pygame

## How to Run

```bash
pip install pygame
python main.py
```
